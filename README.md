A program that draws the open passport spread of the Republic of Nordhavn, a fictional North Atlantic island nation — data page with portrait and machine-readable zone, visa page with entry stamps and a seafarer's endorsement. Pure Python stdlib; it writes /output/entry.png.

## Run it

```sh
python3 main.py
```
